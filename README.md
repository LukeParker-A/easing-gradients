# Easing Gradients

An agent skill for tuning UI gradients, image fades, and scroll-edge masks.

## Install in Codex

With Node.js 22.20 or later, run this from your project.

```sh
npx --yes skills add LukeParker-A/easing-gradients --skill easing-gradients -a codex -y
```

Add `-g` to make the skill available across your Codex projects.
